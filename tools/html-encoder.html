什么是 HTML 实体编码？

HTML 实体编码是一种将 HTML 中的特殊字符转换为 & 开头、; 结尾的字符序列的机制。例如，< 表示小于号 <，& 表示与号 &。这是 HTML 中表示保留字符的标准方式。

为什么需要 HTML 转义？

在 HTML 中，某些字符具有特殊含义：

  • < 和 >：用于定义 HTML 标签，如 <div>。
  • &：用于表示实体编码的开始。
  • "：用于定义属性值，如 class="example"。
  • ' / '：用于定义使用单引号的属性值。

如果需要在网页中显示这些字符本身（而不是让浏览器将它们解析为 HTML 语法），就必须将它们转义为对应的实体编码。

常见 HTML 实体对照表

  • < → &lt; （小于号）
  • > → &gt; （大于号）
  • & → &amp; （与号）
  • " → &quot; （双引号）
  • ' → &#39; （单引号）
  • \u00A0 → &nbsp; （不间断空格）

XSS 防护

HTML 实体编码是防止跨站脚本攻击（XSS）的重要手段。当用户输入的内容需要显示在网页上时，如果不进行转义，攻击者可能注入恶意脚本。例如，输入 <script>alert('xss')</script> 会被浏览器执行。转义后变为 &lt;script&gt;alert('xss')&lt;/script&gt;，浏览器会将其显示为普通文本而非执行。

使用场景

  • 在网页中展示 HTML 代码示例。
  • 防止用户输入导致的 XSS 攻击。
  • 处理含有特殊字符的文本内容。
  • 编码 URL 参数中的特殊字符（部分场景）。
  • 在 JavaScript 字符串中嵌入 HTML 内容。
