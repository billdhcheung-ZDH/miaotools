什么是 URL 编码？

URL 编码（也称百分号编码）是一种将 URL 中的特殊字符转换为 % 加十六进制表示的机制。例如，中文字符"你好"在 URL 中会被编码为 %E4%BD%A0%E5%A5%BD。这是为了保证 URL 在网络传输中的正确性和兼容性。

encodeURIComponent vs encodeURI

JavaScript 提供了两种 URL 编码方法，区别在于编码的字符范围不同：

  • encodeURIComponent：编码所有特殊字符，包括 /、?、&、=、# 等。适用于编码 URL 参数值。
  • encodeURI：保留 URL 结构字符（/、?、&、=、# 等），仅编码非 ASCII 字符和空格。适用于编码完整的 URL。

使用场景

  • 在 URL 参数中传递中文或特殊字符。
  • 构建 API 请求 URL 时的参数编码。
  • 解码从服务器返回的编码 URL。
  • 处理带有特殊字符的链接。

注意事项

URL 编码是可逆的，任何人都能解码，不属于加密。编码后的字符串长度会增加，中文字符编码后约为原长的 3 倍。本工具所有处理均在浏览器本地完成，数据不上传服务器。
