CSV 与 JSON 是什么？

CSV（Comma-Separated Values，逗号分隔值）是一种以纯文本存储表格数据的格式，每行代表一条记录，字段之间用分隔符（通常是逗号）隔开。它结构简单、体积小，Excel、Google Sheets、数据库导出等场景广泛使用。

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式，以键值对和数组组织数据，被几乎所有编程语言原生支持，是 Web API 的事实标准。

为什么需要相互转换？

  • CSV → JSON：从 Excel 或数据库导出的表格数据，转成 JSON 后可直接用于前端渲染、API 请求或存入 MongoDB 等文档数据库。
  • JSON → CSV：从 API 获取的 JSON 数据，转成 CSV 后可在 Excel 中打开做筛选、透视表、图表分析。
  • 数据清洗：在两个格式间来回转换，便于用不同工具处理。

CSV 与 JSON 对照示例

CSV 格式：

name,age,city
张三,28,上海
李四,34,北京

转换为 JSON 后：

[
  { "name": "张三", "age": 28, "city": "上海" },
  { "name": "李四", "age": 34, "city": "北京" }
]

功能说明

  • 自动识别分隔符：支持逗号、分号、制表符、竖线，也可手动指定。自动模式会统计各候选分隔符出现次数，选最可能的那个。
  • 引号转义处理：正确处理 "a,b" 这类内含分隔符的字段，以及 "" 形式的转义引号。
  • 类型自动识别：可选是否将 123、3.14、true、null 转换为 JSON 中的原生类型（否则全部作为字符串）。
  • 反斜杠字面量：CSV 中未加引号的 \n 会被还原为真正的换行符。
  • JSON 转 CSV：支持对象数组与单个对象，自动提取所有键作为表头，非对象值自动降级为单列。

注意事项

  • CSV 没有严格标准，不同软件（Excel / MySQL / Google Sheets）对引号、换行、编码的处理略有差异。本工具遵循 RFC 4180 主流约定。
  • CSV 不支持嵌套结构。JSON → CSV 时，嵌套的对象或数组会被序列化为 JSON 字符串放入单元格。
  • Excel 打开 CSV 中文乱码时，可通过"数据 → 从文本/CSV"导入并指定 UTF-8 编码解决。
  • 处理敏感数据时请放心，所有转换均在浏览器本地完成，内容不会上传到任何服务器。
